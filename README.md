# Outil de Dimensionnement Réseau 5G – Frontend

Ce projet est une application web permettant de créer et gérer des projets de dimensionnement pour un réseau 5G.

## 🚀 Fonctionnalités

- Création de projet avec :
  - Nom
  - Surface (km²)
  - Densité d’utilisateurs
  - Fréquence utilisée (3.5 GHz / 26 GHz)
  - Largeur de bande
  - Type de zone (urbain, périurbain, rural)

- Interface responsive en **Tailwind CSS**
- Développée avec **Next.js**

## 📦 Stack technique

- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/) — Utilisé pour le design moderne et responsive
- [React Icons / Zustand / Axios (optionnel)] — Pour la gestion d'état et les appels API
- [React Hook Form + Zod] — Recommandés pour les validations avancées

## 🛠️ Installation

1. Clone le dépôt :

```bash
git clone https://github.com/Mouhameddiagne2003/5G-Network-Design.git
cd 5G-Network-Design   

2. Installez les dépendances :

```bash
npm install 
```

3. Lancez le serveur de développement : 

```bash
npm run dev
```
